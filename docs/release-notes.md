# 版本更新说明

## v1.1 · 2026-10-20

- 统一行内公式为带代码保护的 GitHub 数学定界符，避免下划线被 Markdown 当作强调标记。
- 独立公式统一使用 `math` 代码块，使块级数学与普通代码明确分开。
- 以基础数学字体宏表达 ReLU、softmax、clip 等名称，减少不同预览器的宏兼容问题。
- 比较符号使用显式 TeX 关系符号，避免 HTML 转义影响概率条件和不等式。
- 阅读页同步解析这两种写法；代码示例中的 PowerShell 变量和反引号保持原样。
- 新增数学文档检查和回归测试，覆盖相邻公式、矩阵换行、代码变量与重复构建。
- 简化项目介绍，版本与许可信息各自集中维护。

新增内容的排版规范见 [公式写作与维护](math-formatting.md)。计算模型、数据划分、数值推导和原有实验结果不因本次排版修复而改变。
