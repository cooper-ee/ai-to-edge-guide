# 公式与术语速查

速查表用来回忆；公式假设与示例请回到对应课。

| 英文 / 中文 | 核心含义 | 易混点 |
|---|---|---|
| Tensor / 张量 | 多维数值与 shape/dtype/stride 等信息 | reshape 不总是实际搬数据 |
| Logits / 未归一化分数 | softmax 前的输出 | 不是概率 |
| Autograd / 自动求导 | 沿计算图求导 | 不负责自己选学习率 |
| Checkpoint / 检查点 | 保存权重或训练状态 | 恢复训练还可能要优化器与 RNG 状态 |
| Tokenizer / 分词编码器 | 文本和 token ID 之间的契约 | 不等于 embedding |
| Prefill / 预填充 | 处理已知输入并建立状态 | 不包含整个请求的全部耗时 |
| Decode / 自回归解码 | 逐步延续输出 | 仍需访问历史状态 |
| KV Cache / 键值缓存 | 保存历史 key/value | 不只是模型权重 |
| GQA / 分组查询注意力 | 多组 query 共享更少 KV 头 | head 数不应全部取 query 头数 |
| PTQ / 训练后量化 | 训练完成后做低位宽近似 | 仍可能需要代表性校准 |
| QAT / 量化感知训练 | 训练时适应量化误差 | 不是简单重存一个 dtype |
| IR / 中间表示 | 编译器用于分析与变换的表示 | 图级和循环级职责不同 |
| Kernel / 计算内核 | 一段具体设备执行程序 | Python 算子可能分解成多个 Kernel |
| TTFT / 首 token 延迟 | 请求提交到首输出 | 包含排队/预处理等边界需定义 |
| TPOT / 平均每输出 token 时间 | 本教程对 $`N\gt 1`$ 用 $`(t_N-t_1)/(N-1)`$ | 不直接等于全服务吞吐倒数 |
| RSS / 驻留集 | 进程当前驻留物理页相关口径 | 共享页与设备缓冲需另查 |
| Artifact / 部署产物 | 与工具链及目标相关的输出 | 后缀一致不保证兼容 |

## 单位与小例子

- 1 MB = $`10^6`$ bytes；1 MiB = $`2^{20}`$ bytes。内存推导统一注明单位。
- FLOPs 是运算量；FLOP/s 是速率。MAC 有的统计为一次操作，有的算两次，比较前核对。
- 矩阵乘 $`[M,K]@[K,N]`$ 约 $`2MKN`$ FLOPs；这里忽略边界加法差异。
- 全注意力 KV payload：$`2BTH_{kv}d_hLs`$，非全注意力层另算。
- 对称量化无裁剪时舍入误差通常不超过半个 scale；发生饱和后不适用。
- Roofline：$`\min(P_{peak},BW I)`$，$`I`$ 的单位为 FLOP/byte。
- Amdahl：$`S=1/[(1-f)+f/s]`$，需明确原始时间比例 $`f`$。
