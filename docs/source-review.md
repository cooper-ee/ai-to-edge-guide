## 哪些是新增，哪些是延续

**新增**：独立量化课、完整小模型交付项目、可训练小 LM、真实缓存等价验证、在线 attention 数值参考、调度守恒测试、HTTP 集成测试、可交互实验台、原创 SVG/GIF、统一报告模板和文档校验工具。

**延续并细化**：原文已正确强调 prefill/decode 区分、版本矩阵、混合注意力不能套全层 KV 公式，以及不能凭 GRQ 缩写猜测算法。本版补充可执行对照与单位推导，不将这些合理观点说成原文错误。

**调整学习优先级**：应用、推理系统和硬件不是一条必须全部顺序完成的链。RAG 不作为编译器前置；先做 CPU 闭环，再进入厂商 SDK；硬件待测与数学参考不混写为已验证性能。

**保留的未知**：未公开的 SDK 内部内存布局、厂商量化算法细节、未运行的板端性能不作推断。外部工具的安装与 API 必须查固定版本官方来源。
